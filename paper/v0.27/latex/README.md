# Portable LaTeX: v0.27 / main artwork R8

Open `main.pdf` to review the six integrated author-redrawn figures. Compile `main.tex` or `supplement.tex` with XeLaTeX, keeping `figures/` alongside both files. For Overleaf, upload this entire folder and select XeLaTeX. Inline references require no external BibTeX database. `python BUILD.py --engine xelatex` builds both PDFs; Tectonic is also supported.
