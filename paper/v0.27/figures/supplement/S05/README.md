# Figure S5 · Participation costs

Waiting and deadline costs, access fees, and the choice of response product.

[Reference PDF](AIDRBench_Supplementary_Figure_5.pdf) · [Preview](AIDRBench_Supplementary_Figure_5.png) · [Editable SVG](AIDRBench_Supplementary_Figure_5.svg) · [Plotting workbook](S05_READY.xlsx)

To redraw this figure, run `python redraw.py` from this directory, or `python tools/aidr.py redraw --figures S5` from the repository root. Install the [plotting dependencies](../../../../../docs/getting-started.md) first. Output is written to the supplementary pack's `MY_REDRAW/` directory, not over the reference files.

Percent, percentage-point and currency columns are already converted for plotting. Piecewise boundaries include their breakpoints.

The renderer reads the local CSV files, not the workbook. Use [series assignments](../PLOT_ASSIGNMENTS.csv) for X/Y and interval columns and [English captions](../FIGURE_LEGENDS_EN.md) for definitions and comparison conditions. The [editing guide](../README.md) explains data formats and how to insert an approved figure into the paper.
