# Non-locked representative validation artifact

This directory contains the single validation scenario used for Supplementary Figures 3 and 4 and a copy of the frozen q = 0.95 capacity-selection receipt. It exists so that all supplementary figures can be regenerated from a clean repository checkout without publishing or reopening the full validation ensemble.

The scenario was selected by the predeclared deterministic rule `minimum_episode_seed`:

- episode seed: 20,000;
- scenario SHA-256: `c53ae573b0664487ef9674ac8f746f47e59c1e10b31f872f34607fdfd247e7e8`;
- selection receipt SHA-256: `ddd0094907e34f7f137856169c5fd6b84a33cf37cfc48e5158ceb5502fdd470b`.

This example is non-locked and descriptive. It is not an independent reliability certificate, a replacement for the 100-scenario validation set, or an input to capacity selection.
