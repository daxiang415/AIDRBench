# Historical results

All results produced under `firm_v1` through `firm_v4`, early reward variants,
coarse capacity grids, repeated-event controller certificates, and the old
RL-centred protocol are historical diagnostics. In particular, previously
reported values such as 63.52 kW, 67 kW, and 68.86 kW must not be cited as the
current Nature Communications firm-flexibility boundary unless they are
recomputed on the new single-event protocol with the declared confidence rule.

The detailed audit trail remains in `docs/hourly-validation-status.md` and the
corresponding `results/` directories. The old protocol manifest
`data/manifests/hourly_experiment_protocol_v2.yaml` is preserved only so those
artifacts remain interpretable.
